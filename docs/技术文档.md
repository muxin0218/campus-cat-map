# 校园流浪猫地图 — 技术文档

## 1. 项目概述

校园流浪猫地图是一个基于 Web 的校园流浪猫信息管理平台，旨在帮助校园师生记录、追踪和关爱校园内的流浪猫。用户可以通过地图浏览猫咪位置、进行偶遇打卡和投喂打卡、查看数据统计，管理员可以审核用户提交的内容。

### 1.1 项目目标

- 可视化展示校园流浪猫的分布位置
- 提供便捷的打卡记录功能（偶遇 / 投喂）
- 建立猫咪档案与图鉴系统
- 提供数据看板，展示打卡趋势与统计信息
- 实现用户注册登录与管理员审核机制

### 1.2 技术栈

### 2.1 架构说明

- **前端**：单页应用（SPA），通过 HTTP API 与后端通信
- **Express 后端**：提供业务数据 API（猫咪、打卡、投喂等），连接 PostgreSQL
- **FastAPI 认证服务**：独立的 Python 服务，处理用户注册、登录、JWT 签发
- **审核机制**：用户新增的记录默认 status = `pending`，管理员审核通过后变为 `approved`，普通用户只能看到已通过的内容

## 6. 核心功能实现

### 6.1 审核机制

1. 用户提交猫咪 / 打卡 / 投喂记录时，后端自动设置 `status = 'pending'`
2. 普通用户查询时，后端通过 `statusFilterClause` 中间件自动添加 `AND status = 'approved'` 过滤
3. 管理员查询时，可通过 `?status=pending` 参数获取待审核内容
4. 管理员在前端审核页面点击"通过"或"拒绝"，后端执行 UPDATE 更新 status

### 6.2 认证机制

- 前端调用 FastAPI 认证服务进行注册 / 登录
- 登录成功后获取 JWT token，存储在 localStorage
- 前端请求 Express 后端时，通过 `Authorization: Bearer <token>` 头传递身份信息
- Express 后端通过 `parseAuth` 中间件解析 JWT，挂载到 `req.authUser`
- 管理员接口通过 `requireAdmin` 中间件保护

### 6.3 地图展示

- 使用 Leaflet 地图 + OpenStreetMap 瓦片
- 首页加载所有猫咪位置（绿色标记）和投喂点（橙色标记）
- 点击标记弹出信息窗口，可跳转详情页

### 6.4 数据看板

- 核心指标卡片：猫咪总数、打卡数、投喂数、点位数量
- 近 7 天打卡趋势折线图
- 猫咪性别分布与绝育状态饼图
- 明星猫咪排行榜（Top 3）
- 积极用户排行榜（Top 3）

## 7. 部署与运行

### 7.1 前置要求

- Node.js 18+
- Python 3.10+
- PostgreSQL 14+
- pnpm（推荐）或 npm

### 7.2 环境变量

#### Express 后端（backend/.env）

```
DATABASE_URL=postgresql://user:password@localhost:5432/campus_cat_map
JWT_SECRET=campus-cat-map-secret-key-change-in-production
```

#### 前端（.env）

```
VITE_API_BASE_URL=http://localhost:3000
```

### 7.3 启动步骤

```bash
# 1. 安装依赖
pnpm install

# 2. 配置数据库
psql -U postgres -d campus_cat_map -f db/schema.postgres.sql
psql -U postgres -d campus_cat_map -f db/seed.postgres.sql

# 3. 启动 Express 后端（端口 3000）
pnpm --dir backend dev

# 4. 启动 FastAPI 认证服务（端口 8000）
pip install -r backend-python/requirements.txt
python backend-python/main.py

# 5. 启动前端（端口 5173）
pnpm dev
```

### 7.4 访问地址

- 前端：http://localhost:5173
- Express 后端：http://localhost:3000
- FastAPI 认证：http://localhost:8000
