
# 校园流浪猫地图设计

  This is a code bundle for 校园流浪猫地图设计. The original project is available at https://www.figma.com/design/O22Nw44jSzqvB7em40FXBW/%E6%A0%A1%E5%9B%AD%E6%B5%81%E6%B5%AA%E7%8C%AB%E5%9C%B0%E5%9B%BE%E8%AE%BE%E8%AE%A1.

## 本地运行

推荐使用 `pnpm`：

- 安装依赖：`pnpm install`
- 本地启动：`pnpm dev`
- 构建产物：`pnpm build`

## 在线预览（GitHub Pages）

仓库推送到 `main` 分支后，会自动构建并部署到 `gh-pages` 分支（GitHub Pages 传统部署方式）。

启用方式：`Settings → Pages → Build and deployment → Source: Deploy from a branch`，选择 `gh-pages / (root)`。

预览地址格式：`https://muxin0218.github.io/campus-cat-map/`
